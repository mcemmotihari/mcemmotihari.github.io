# Data files

Edit CSVs, then open a PR to `main`. CI rebuilds the website.

## Shared catalogues

| File | Edit when… |
|------|------------|
| `sections.csv` | Add a class, change **w.e.f.**, or set `status` to `active` / `archived` |
| `subjects.csv` | Adding a paper code / L-T-P |
| `faculties.csv` | Adding a teacher |
| `rooms.csv` | Adding a classroom or lab |
| `meta.yaml` | Changing period timings (rare) |

## Per-class timetable

Each branch + semester has its own folder. Edit only that class:

```
data/schedules/CSE-3/slots.csv
data/schedules/CSE-3/offerings.csv
data/schedules/CSE-3/history/2026-08-13/   # frozen earlier editions (optional)
```

`status` on `sections.csv` hides a class from the live site without deleting files (`archived`).

When a new notice is issued (new w.e.f.), freeze the old grid first:

```bash
python3 scripts/new_edition.py CSE-3 --wef 01/09/2026
```

That copies the current CSVs into `history/<old-wef>/` and updates `wef` on the section. Then edit the current `slots.csv`. The class page lists those frozen dates in the Edition dropdown.

`timetable.json` is generated by CI — no need to edit it by hand.
