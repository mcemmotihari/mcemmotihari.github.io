# Data files

Edit these CSVs, then open a PR to `main`. CI rebuilds the website.

| File | Edit when… |
|------|------------|
| `slots.csv` | Changing the weekly grid (main file) |
| `sections.csv` | Adding a class / semester / branch |
| `subjects.csv` | Adding a paper code / L-T-P |
| `faculties.csv` | Adding a teacher |
| `rooms.csv` | Adding a classroom or lab |
| `offerings.csv` | Assigning a subject+faculty to a section |
| `meta.yaml` | Changing period timings (rare) |

`timetable.json` is generated by CI — no need to edit it by hand.
